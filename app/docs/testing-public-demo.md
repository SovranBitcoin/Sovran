## Runtime isolation

`usePresentationPubkey` applies the public viewer only to header/drawer display
and public-profile navigation. `useProfileDisplay` and
`getMockProfileMetadata` choose reviewed metadata only while Mock Mode is on.
The relay/entity/profile stores are never populated from the fixture. Disabling
Mock Mode immediately restores live readers, including the header and drawer.

Contacts suppresses live DM queries and excludes existing private conversations while
Mock Mode is enabled. Fictional conversations never fetch, publish or offer payment
actions, including after the mode is disabled on a mounted conversation.

Feed cards and notification actions remain read-only. The existing local AI and
wallet presentation fixtures remain synthetic and independent of the public
social snapshot. A public npub does not authorize payments, AI billing or
publishing. The native store journey asserts the drawer shows `kelbie` in Mock
Mode and stops showing it after disabling the mode on its fresh test wallet.

`publicDemoSnapshot.test.ts` verifies every retained event's signature, the
viewer/follow relationships, notification recipient/target ownership, repeated
mode toggles, and preservation of actual account metadata. The asset setup in
`jest.staticAssets.js` adapts React Native's `{ testUri }` test representation to
Expo Asset; actual rendering is verified separately on native devices.

To update the snapshot, fetch public candidates again, review text and every
image, preserve original signed events, and rerun the focused tests and both
native galleries. Do not automatically replace reviewed data during captures.

## Preview renderer repair

The first native review exposed raw `nostr:nprofile...` strings in notification
previews. `notificationPreviewText` now uses the existing checksum-validating
feed parser to display known profile references as `@name`, with a short public
identifier fallback for unresolved references. It leaves the signed event and
ordinary text/URLs unchanged. Live notification enrichment now includes mentioned
profiles, so the fix applies to real notifications too. Three regression checks
cover the real selected mention, invalid references, unresolved names, and literal
replacement characters. The initial iPhone diagnostic run was interrupted after
this finding and its owned simulator was deleted; it is not an upload set.
