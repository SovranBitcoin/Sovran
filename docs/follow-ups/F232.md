Pass 2 made each answer one turn owned by its conversation. Left: text that arrived before an answer stopped is
kept in memory only, so it survives leaving the screen but not an app kill (saving it needs a marker that an answer
is partial; without one a restart would read it as finished); a stream error drops the text already shown; a stream
that ends without its end marker is saved as a finished answer (`app/shared/lib/routstr/api.ts` about line 1164);
backgrounding the app does not stop a stream; a question typed in a brand-new chat, or one with no saved conversation, is dropped when its
send is abandoned because the conversation or account changed, since there is no saved conversation for it to wait
in.

## Done when

The owner has ruled on saving partial text; an unmarked end reads as interrupted; an abandoned first question is not lost.
