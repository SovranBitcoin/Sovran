Seen on 2026-10-13 in every run of the end-to-end state story `app/e2e/stories/states/testnut-mint.json`. After
`testnut.cashu.space` is chosen in the mint list of a wallet with no money, the log shows

```
wallet.unit.synced_to_mint   from: sat  to: tsat   source: highest_balance_at_mint
store.mint.set_active_unit   from: sat  to: tsat
store.mint.set_active_unit   from: tsat to: tusd     (about 400 ms later)
```

and the wallet home lands on "Test USD account". The story then swipes the balance back to the test bitcoin
account. Which code makes the second change was not looked for.

Left because it may be intended (a preference for the last unit a mint lists) and nobody has said.

## Done when

Either the wallet stays on the account it first chose for the mint, or the second change is explained where it
is made.
