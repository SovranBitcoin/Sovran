Two windows in which the testnut account split is computed from verdicts the app does not have yet, so mint lists correct themselves after the fact. (a) `mintTestnutStore` is AsyncStorage-persisted but, unlike `themeStore` / `wallpaperStore` / `walletLifecycleStore`, tracks no `_hasHydrated`, and nothing gates on it — before it rehydrates every mint reads as real, so a `tsat` account momentarily has no mints at all. (b) A mint nagg has not probed has no verdict, and `isTestnutMint` answers `false` (real) until `refreshMintTestnutVerdicts` returns, which is a network round-trip, not a frame. Deliberately not fixed here: "unknown" cannot be answered synchronously, so the fix is a product decision (gate the picker, or show an explicit unverified state). Window (b) is now 10 minutes rather than 24 hours (`UNPROBED_RECHECK_MS`), after a captured session offered "as Onchain" for 1 sat through an unclassified testnut mint; window (a), and the fact that an unprobed mint still counts as REAL in between, remain.

## Done when

The picker never renders rows derived from an unhydrated or unprobed verdict; a `tsat` account shows a loading state rather than an empty list
