Not every route, alias, gesture and modal exit has a native journey on both platforms.

**Pinned on 2026-10-11; authoring and running are what is left.** `bun run e2e:pages` shows 24 pages that no
scenario reaches. They are now listed in `app/e2e/schema/page-journey-gaps.ts`, and
`app/e2e/page-journeys.test.ts` fails when a page has no journey on either platform without being listed, or is
listed while having one, so the list can only shrink. Five are capability gaps with a reason (a second Bluetooth
device, a controlled chain backend). Nineteen are marked `unauthored`: nothing is in the way but the work, and a
scenario written without a simulator to run it on would be a guess. For each: author the smallest journey that
enters, operates and leaves, run it on iPhone and Android, and delete its line. `signer-connect` only needs
`wallet.deeplink.nostrconnect` to name its screenshot for the page it is on. Gestures, route aliases and modal
exits are not counted by this check.
