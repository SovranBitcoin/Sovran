`AccountMismatchScreen` has test IDs (`account-mismatch-screen`, `account-mismatch-view-recovery`, `account-mismatch-copy-code`, `account-mismatch-switch-<index>`, `account-mismatch-enter-phrase`, `account-mismatch-dismiss`) and labels but, like the startup failure screens in F79, no canonical page entry and no native scenario: the JSON harness cannot plant a profile row that disagrees with the keychain. Covered by `accountMismatchScreen.test.tsx` and `accountIntegrityStartup.test.tsx` only.

**Not started on 2026-10-12, for the same reason as the startup-failure screens:** planting a profile row that
disagrees with the keychain needs a harness fixture that writes storage before launch on a disposable install,
and it has to be run on both platforms to be worth anything. What is left: that fixture, a canonical page entry
for the screen, and a scenario that enters it, copies the code and switches away.

## Done when

The harness can start the app with a mismatched row on a disposable install, and a scenario enters the screen, copies the code and switches away on both platforms.
