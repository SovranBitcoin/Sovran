id: F183
title: "BitChat drops a failed public or geohash send without telling the person"
priority: medium
needs: decision
---

`useBitChat` catches a rejected native send for public, geohash and Nostr direct messages, removes the optimistic
row and resolves; `ChatScreen` has already cleared the draft. Nothing is shown and the text is gone. No test covers
it. Left because how a failed message is shown (failed row, restored draft, notice) is a design choice.

## Done when

A failed send leaves the text recoverable and visibly failed.
