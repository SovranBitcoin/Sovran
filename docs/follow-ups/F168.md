`Controller.verify` in `harness/src/controller.ts` runs the historical upgrade suite for every
application or wallet change and judges it with `inspectUpgradeEvidence`
(`harness/src/upgrade.ts`). On main it returns inconclusive whatever the change, with
"Missing ordinary evidence: E7: keeps the wallpaper theme … E17". Both full-send tasks that
reached verify on 2026-10-16 ended there, so no app task has passed the gate. Left because it
needs someone to find whether the epoch fixtures or the inventory changed under the
inspector, which was outside the harness device work.

## Done when

`bun run --cwd app test:upgrade --json` on clean main satisfies `inspectUpgradeEvidence`, and a
no-op app change passes the upgrade stage of `verify`.
