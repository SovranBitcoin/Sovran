title: "Three places that keep the newest replaceable event break a same-second tie by arrival order"
priority: low
needs: fix
---

NIP-01 says that of two replaceable events with the same `created_at`, the one with the lowest id wins. `latestKind0ByPubkey` in `nostr/src/envelope.ts`, `parseWallpaperCatalog` in `nostr/src/recipes/wallpapers.ts` and `partitionOwnEvents.ts` keep whichever arrived first, so two phones can settle on different profiles or contact lists from the same pair of events. Read on 2026-10-12 from `docs/review/sweep-ledger.md`.

## Done when

All three use one comparison (newer `created_at`, then lower id), with a test for the tie.
