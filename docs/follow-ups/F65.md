The Details modal is a route (`app/details.tsx`, [ADR 0026](../../app/docs/adr/0026-details-and-pickers-are-sheets.md) amendment) registered as the canonical page `details`, with unit tests for the hand-over, the split table, the footer and the three-dots rule. It has not been opened on a device, and no JSON scenario enters it. Unverified natively: the page sheet stacking over another route modal on iPhone, the pushed page inside Android's flows, the footer clearing the home indicator, and the one-item three-dots menu on the receive screens.

## Done when

A scenario opens a Lightning receive, opens Details from the dots, copies a row, taps Done and returns, on both platforms; screenshots confirm the footer and the sheet stacking
