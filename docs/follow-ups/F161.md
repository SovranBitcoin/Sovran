The baseline acceptance of nonexistent finding evidence is corrected. Finding and artifact
references are checked, retained obligations need dispositions, and final audit revalidates
artifacts. The named Node collector rejects missing or skipped required cases, incomplete
streams and expected-failure inversion. Sealed regression inputs compare recognized assertion
failures on the baseline with candidate results; independent oracle judgments are required.
These are bounded local checks,
not proof that an agent selected adequate tests or that every runner has equivalent coverage.

Remaining validation must challenge the test oracle and reviewer with misleading but plausible
results, valid alternative fixes, weakened assertions and intermittent failures. Exercise the
[research test matrix](../research/full-send-reliability.md) with real workers and held-out cases.
This work concerns evidence acceptance, not additional wallet behavior.

The isolated remote-base extraction exposed a runtime prerequisite: one regression-inversion
test fails under Node 23.10.0, while the development checkout uses Node 24.14.1. The older
runtime ignores the newer expected-failure option. The collector now rejects runtimes without
that capability before loading candidate tests. Validate the supported runtime in the extracted
environment before treating the development results as portable.

## Done when

Finding references receive appropriate existence/boundary/freshness validation and deferred
findings have real ledger dispositions. Zero-test, early-exit, skipped-required-case, partial
or fabricated report fixtures cannot qualify a task. Legitimate test additions remain
possible, while removed tests, filters, weakened assertions and changed runner authority
receive independent review. Tests establish actual outcomes, not merely prompt wording.
Important regression tests distinguish valid and invalid behavior: an old-code compile
failure does not count as reproducing the bug, and expected results do not simply repeat
the implementation. Preserve all rerun outcomes; a later pass cannot erase an unexplained
failure. Exercise misleading green reports, unrelated setup failures, equivalent deliberate
faults, weakened snapshots/mocks and intermittent product failures labelled as test flakes.
The native producer/action gaps remain owned by F149/F156.
