At baseline f12db054d, Controller.submit checks observation paths but accepts a nonexistent
findings.evidence path. Reproduction: create a disposable task, submit passing research with
a valid observation and a follow-up finding pointing at absent.ts; it advances to intake.

Ordinary checks also seal argv, not the meaning of a mutable package script/test runner.
Unlike the specialized historical upgrade parser, they can report success without proving
required tests ran. See the [research test matrix](../research/full-send-reliability.md).
This work concerns evidence acceptance, not additional wallet behavior.

## Done when

Finding references receive appropriate existence/boundary/freshness validation and deferred
findings have real ledger dispositions. Zero-test, early-exit, skipped-required-case, partial
or fabricated report fixtures cannot qualify a task. Legitimate test additions remain
possible, while removed tests, filters, weakened assertions and changed runner authority
receive independent review. Tests establish actual outcomes, not merely prompt wording.
