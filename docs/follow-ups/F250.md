The Wallet / Settings / Search tab bar, the Search tab (native header search bar on iOS, glass
field on Android), the Settings tab header and the account switcher drawer were checked by
type-check and Jest only; no simulator or phone was available. Unseen: the iOS 26
`role="search"` item joining the header search bar, tab label colours in light and dark, the
Wallet `MintSelector` staying centred with only a left header item, Android label scaling in
the 56pt row, the drawer's 32pt swipe edge against the account carousel, the long-press menu
and import form opening only after the drawer has closed, and a profile switch holding every
row until the restart. No native harness scenario covers the new `tab-settings`, `tab-search`,
`search-screen`, `drawer-add-account` or `drawer-import-account` ids yet.

## Done when

Each item above has been seen working on an iPhone with iOS 26 and on Android, with screenshots
or a clip, and a native scenario enters each new tab and the drawer and leaves again.
