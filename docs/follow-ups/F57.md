Offline ecash send ([ADR 0019](https://github.com/SovranBitcoin/Sovran/blob/main/app/docs/adr/0019-an-exact-send-needs-no-mint.md)): `ops.send.prepare({ offline: true })` via a patch to `@cashu/coco-core@2.0.0` compiled from `app/patches/sources/`, and local-first exact bearer routing in `runConfirmSendEffect` (ADR 0020). Tested against the installed bundle with a failing `fetch`. Run on an iPhone (iOS 26.7.1, dev build) on 2026-10-12 with Airplane Mode on, the app already open: 4 sat, exact match, one send operation, no request to the sending mint, the token page showed the device-offline notice. Not yet run: Android, and a send after a cold start with no network. Non-exact and locked sends still depend on Coco's mint requests, which have no timeout. Offline receive shares coco's refresh and was not examined. No E2E scenario sends with mint data older than five minutes.

## Done when

An airplane-mode send succeeds on iPhone and Android after a cold start; an E2E scenario covers stale mint data; offline receive is characterized; the option is proposed upstream and the patch removed once a release carries it
