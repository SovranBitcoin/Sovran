id: F182
title: "An own-profile event with an equal timestamp and a lower id is ignored when it arrives in a later batch"
priority: low
needs: fix
---

`useOwnEventsSync` admits a profile event only when its `created_at` is greater than the last applied one, while
`partitionOwnEvents` and the package's `supersedes` break ties by lower id. Splitting the same events across batches
changes which profile is cached. `app/__tests__/useOwnEventsSync.test.tsx` pins this. Left because it decides what is
written to the cached profile.

## Done when

The hook uses the same ordering as `supersedes`, and the pinned assertion is changed on purpose.
