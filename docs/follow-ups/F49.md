The manual hosted-balance top-up flow has been replaced by SDK pay-per-request. The model picker and send gate now use one compatible mint's spendable sats and recheck after confirmation. Automatic cross-provider retry is prohibited; an uncertain outcome retains recovery material.

## Done when

A controlled native payment shows the chosen provider and mint, admission amount, returned change and final cost; insufficient funds sends nothing, and uncertain failure never pays another provider
