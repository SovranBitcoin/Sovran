`bun run docs:build` (the Docs workflow's `build` job) fails on `main` at `82c8add85`, and on
every branch made from it, with "22 dead link(s) found". Each one is a relative Markdown link
from a page under `docs/` to a file outside the VitePress site: the app's ADRs in
`app/docs/adr/`, `harness/README.md`, and skills under `.agents/skills/`. VitePress checks only
pages it builds, so these links work on GitHub and fail the site build. The pages include
`research/full-send-reliability.md`, `protocols/navigation-and-routes.md`, the persistence
ledger pages, two dated architecture audits and follow-ups F58, F59, F60, F64, F65, F68,
F159 and F160.

It was found while checking PR #291's CI, which fails on the same 22 links, and was left
because none of them come from that branch.

## Done when

The Docs workflow passes on `main`. Either links that leave the site point at their GitHub
URL, or the VitePress config's `ignoreDeadLinks` names exactly these outside paths, so that a
link to a missing page inside the site still fails the build.
