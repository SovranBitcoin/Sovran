Traced by reading, not run. When add profile, import key, delete everything or switch gives up after raising the
splash (keychain refuses the key, profile list full, key derivation times out), the splash reset in
`app/shared/providers/InitializationProvider.tsx` empties the stage map and the mounted providers never register
again; `CocoProvider`'s cleanup then runs `CocoManager.cleanup()` and renders nothing until the app is killed.
`docs/architecture/account-lifecycle.md` says the app carries on as the previous account. No test reaches this.

## Done when

A rendered test gives up each flow after the splash and the previous account's wallet is still open and on screen; or the trace is shown wrong.
