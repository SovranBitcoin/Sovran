`ReceivePaymentRequestQuoteScreen` starts at `requested` and only moves on later `receive-op:*` events; it never
reads the operation's current state, and its state is not keyed to the operation id.
`app/__tests__/receivePaymentRequestQuoteScreen.test.tsx` pins this. Left because the read it needs (the recorded
receive attempt for the request) was not traced to a single owner.

## Done when

Opening the screen for a request that has already been paid shows it as received.
