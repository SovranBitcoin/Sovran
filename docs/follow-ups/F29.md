---
id: F29
title: "SecureStore key blobs are not shape-checked; useMnemonic never reports a failed read"
priority: high
needs: investigation
---

SecureStore key blobs (cached derived keys, Cashu mnemonic, seed) are `JSON.parse(…) as {…}`; `parseOrSelfHeal` only heals on a throw, so a wrong-shaped blob is returned as valid. Shape validation must match every format ever written, because a parse failure deletes the key. `useMnemonic` also never sets its `error` state and its mount effect voids a read that can reject.

## Done when

Schemas proven against historical blobs; a wrong shape heals without deleting a recoverable key; the hook reports a failed read
