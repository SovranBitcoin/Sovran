The Contacts tab was the only screen that called `useNip17RecentContacts`
(`features/payments/hooks/useNip17RecentContacts.ts`), which reads conversations through
`useDmConversations` and `dmSnapshotCaches`. With the tab gone (ADR 0035) only tests reach
them. They were left because the readers sit on the saved DM caches (`dm-last-message-store`,
`nip17-unwrap-cache:v1`, `nip04-cache:v1`), and removing code next to saved data is reported,
not done, in a navigation change. `useDmEcashAutoRedeem` and payment-request replies do not
use these hooks.

## Done when

Either a screen uses recent contacts again (for example Send's quick-pay row), or the unused
hooks are deleted with the saved stores still registered, still wiped by Delete account, and
`cd app && bun run test:upgrade` passing.
