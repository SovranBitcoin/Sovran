---
id: F80
title: "Removing a profile can strand a payment sent to it that this device has not received"
status: open
priority: low
needs: fix
---

Removing a profile cannot see a payment that was sent to it but that this device has not received: the profile is not running, and removal by design does not use its keys or the network (ADR 0030). Such a payment is addressed to a request id that is deleted with the profile, so adding the profile back does not collect it automatically. The removal prompt now says to open the profile first if it may have been paid recently.

## Done when

Removal offers to open the profile and sync before deleting, or keeps the request id so a re-added profile can still collect.
