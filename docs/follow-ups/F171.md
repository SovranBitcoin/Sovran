---
id: F171
title: "Harness simulators appear as windows whenever Simulator.app is open"
priority: low
needs: upstream
---

Story runners boot their simulators with `simctl`, which opens no window, but Simulator.app,
when someone has it open, shows every booted simulator in Apple's default device set. A
separate device set (`simctl --set`) would hide them, but the `serve-sim` native addon that
`storySimulator` in `app/e2e/stories/simulator.ts` uses for touches and the accessibility tree
only looks up devices through `SimServiceContext defaultDeviceSetWithError:`. Left because it
needs a change to that package.

## Done when

`serve-sim` can address a simulator in a named device set, and the story runners create theirs
there, so an open Simulator.app shows none of them.
