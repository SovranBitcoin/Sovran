title: "A Whitenoise inbox start that fails before subscribing is not retried"
priority: medium
needs: fix
---

`useWhitenoiseInbox` now reports a failed start (`whitenoise.inbox.start_failed`) and treats an unreadable cursor as
none, so the inbox still starts. A failure while resolving the inbox relays or opening the subscription still leaves
no inbox until the hook's inputs change or the app restarts. Left because when and how often to retry is a choice.
Pinned in `app/__tests__/whitenoiseInboxRequests.test.tsx`.

## Done when

A start that fails before subscribing is tried again without a restart.
