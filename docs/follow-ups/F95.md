id: F95
title: "Recovery with an unreadable keychain accepts any phrase for imported accounts"
priority: low
needs: fix
---

With an unreadable keychain and only imported accounts saved, recovery accepts any valid phrase, and those accounts' wallets are then derived from the new phrase. Nothing stored records which phrase an imported account's wallet was made with, so the integrity check cannot see it. `NostrKeysProvider`'s `refresh` also derives and stages keys without the loader's check; nothing calls it today.

**Half done on 2026-10-12.** `NostrKeysProvider`'s `refresh`, which derived and staged keys without the loader's
check, is removed; nothing called it. The fingerprint is still to do.

## Done when

An imported account records a fingerprint of its wallet phrase (an additive field) that recovery and the check compare.
