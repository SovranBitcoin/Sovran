The controller and publisher have local integration tests, including real SQLite, git remotes,
processes and an MCP client. A live T3 Luna research ticket was claimed, completed and accepted
at intake. The full sequence through Sol, Opus, Fable, audit, GitHub publication and CI has
not run against live services. The attempted Claude/Fable review on 2026-10-16 failed with
`Claude API rate limit reached`. No substitute provider supplied that required review.

This is a validation gap, not permission to skip the controller's gates. Use a disposable,
unfunded source task and an explicitly authorized test repository. Preserve actual child
identities, terminal states, artifact inspections and observed GitHub checks. Exercise a
controller restart and a repair round; never retry an ambiguous PR creation blindly.

## Done when

One complete live task reaches ready with the sealed providers and actual required CI checks,
creates exactly one PR, links it to T3 and leaves merging to the owner. A restarted task
reconciles its existing child/PR instead of duplicating either. Record the evidence and any
remaining failures without claiming native or wallet safety from this tooling pilot.
