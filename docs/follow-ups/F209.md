title: "Following someone can replace the person's whole public follow list with one entry"
priority: high
needs: decision
---

The Follow button builds the kind 3 event it publishes from the saved contacts tags (`contactsTags` in
`nostr-social-store`), while the list on screen (`followingPubkeys`) can come from nagg without those tags. When the
tags are empty, a follow publishes a list holding only the new person, which replaces every earlier follow on the
relays. Two ways in: the own-events subscription asks for kind 3 only from the last year, so an older contacts list
never arrives; or nothing has loaded yet. Found independently by two surveys (`.surgery/pass-2/surveys/stores.md` D1 and candidate 1,
`.surgery/pass-2/surveys/feed-social-nostr.md` D1 and candidate 1). Traced, not run; no test covers either path. Left because the repair
is a choice (refuse to follow until the list has been read, or read it from the relays first and refuse if that
fails) and it changes what is published.

## Done when

A follow never publishes a contacts list unless the app holds the person's current one, with a test for the empty-tags and the older-than-a-year cases.
