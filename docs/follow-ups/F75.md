Profile removal awaits native work with no time limit (reading the removed profile's wallet database, then deleting its storage). Recovery and profile creation are bounded (`settleWithin`); removal is not, because giving up partway through a deletion and releasing the lock is worse than waiting.

## Done when

The read-only inspection is bounded on its own, before anything is deleted.
