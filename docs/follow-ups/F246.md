The changes on `surgery/decisions-1` have automated test and Metro-bundle evidence, but the new
relay editor and the changed payment outcome presentation have not been exercised on either native
platform. The relay review/cancel scenario is registered but its `relay.controlled` capability is
unavailable, so its dry-run is deferred. Component tests replace native visual primitives and do not
prove layout, focus, accessibility, or native control operation.

Provide a controlled relay fixture and run the Network flow on iPhone and Android: read, edit,
review, cancel, failed read, changed remote base, account switch, and safe test-identity publication.
Never publish for a real identity or pay from a real wallet as a test. Inspect the unknown-payment
wording and fee-review flow with controlled payment outcomes. The existing rebuilt iOS upgrade
record predates these decisions; it is not evidence for the current screen. Android upgrade and
store-signed phone verification remain outside the evidence already gathered.
