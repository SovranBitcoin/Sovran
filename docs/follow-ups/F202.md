`app/features/nearPay/lib/nearbyPayments.ts` records `bleAccepted` (about line 312) and never reads it, so the
Bluetooth copy is sent again every 30 seconds for as long as the send is pending. Pinned in
`app/__tests__/nearbyPaymentDmRetry.test.ts`. Left because it changes the nearby payment protocol's timing; the
receiver dedupes, so no money is at risk.

## Done when

An acknowledged Bluetooth delivery is not sent again.
