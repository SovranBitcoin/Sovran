priority: medium
needs: fix

Nagg wire schemas in `nostr/src/schemas.ts` and `wallet/src/nostr-mint-enrichment.ts` leave event `id`/`pubkey` as plain strings and `content`/`tags` uncapped. The envelope parses `events` as a strict array, so tightening first needs per-item tolerance or one bad event drops the page. `ignoreStore` repeats a lowercase-only 64-hex regex inside a persisted schema.

**The envelope is done on 2026-10-12.** `NaggEnvelopeSchema` parses `events` one by one, so an event that is
malformed or over a ceiling is left out and the rest of the page is kept, and the event schema requires hex ids
and bounded `content` and `tags` (see the note in F45). Left: the same treatment for the review events in
`wallet/src/nostr-mint-enrichment.ts`, and one shared hex schema for `ignoreStore` that still loads the lists
already saved (ids there were written lowercase by the app, but a saved list must never be rejected for one bad
entry, so it needs a tolerant array, not a stricter one).

## Done when

Per-item tolerant arrays; hex ids and size caps on network input; shared id schemas in `ignoreStore` without rejecting stored blobs
