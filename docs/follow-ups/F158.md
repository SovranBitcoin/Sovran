title: "Web export cannot resolve the platform-only GlassSearchBar"
priority: low
needs: fix
---

On 2026-10-16, `expo export --platform all` failed its web bundle because
`app/shared/ui/composed/GlassSearchBar/index.ts` re-exports `./GlassSearchBar`, for which
only native platform implementations exist. The import reaches the feed layout through
`SearchLayout`. Separate iOS and Android exports both succeeded. The task harness does not
change this component; changing app web support was outside that task.

## Done when

The web export resolves this component using an appropriate existing web control or explicit
web implementation, and the search behavior is checked in the browser. Keep both native
exports passing. If web export is deliberately unsupported, make the supported export
command and platform boundary explicit instead of claiming an all-platform export passed.
