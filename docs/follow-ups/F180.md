title: "Standing-quote work that outlives a profile switch can write into the next profile"
priority: high
needs: investigation
---

`ensureReusableMintQuote` and `rotateReusableMintQuote` (`wallet/src/quotes/reusable.ts`) write the new quote id
through the identity store after their create resolves. `disposeReusableQuoteFlights` drops the in-flight map but
cancels nothing, and the app's store (`app/features/receive/lib/standingQuoteIdentityStore.ts`) writes to whichever
profile is active at that moment. Two rotations waiting on one ensure also both create, and the last to finish wins.
Found by review; the path was read, not reproduced across a real switch. It writes saved data, so it was left.

## Done when

A create that finishes after its wallet was disposed writes nothing, and concurrent rotations for one key create once.
