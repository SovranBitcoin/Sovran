title: "Own-account sync can overwrite newer local state with older or empty answers"
priority: medium
needs: decision
---

Four cases, each pinned as it is. (1) `relayListStore.setFromRelay` lets an older list from the network replace newer
local relay edits (`app/__tests__/useOwnRelayListSync.test.tsx`); the pool is also seeded with a list the store
refused. (2) `ownProfileSync` has no timestamp check, so an empty answer wipes the cached name and picture
(`app/__tests__/ownProfileSync.test.ts`). (3) `useOwnSocialGraphSeed` marks the account seeded before it knows a
tier exists and never retries (`app/__tests__/ownSyncLifecycle.test.tsx`). (4) `giftWrapCache` remembers a failed
unwrap for good, even when the right key is later used (`app/__tests__/giftWrapCache.test.ts`).

## Done when

Newer local state is never replaced by an older or empty answer, a seed that could not run is retried, and a failed unwrap can be tried again with a different key.
