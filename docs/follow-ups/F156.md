one launch. The strengthened run is `run-2026-10-16T09-19-34-671Z-211c7c11`; an earlier clean
`c61dbe362` run exercised the original story. Both retain the F142 standing-request warnings

The iOS run is `run-2026-10-16T09-31-21-091Z-220392f0`. Its private wrapper compared the whole

## The bound story gate

The controller now accepts UI work through a sealed `native` requirement (`harness/src/native.ts`):
`app/e2e/stories/bound.ts` builds both bundled apps afresh and plays each sealed story on a
disposable device; the controller checks the raw evidence, not the runner's verdict, and a
story-oracle review must cite the stories and the inspection. Android runs are recorded on video.

On 17 October, before the rebase onto `82c8add85`, a manual bound run of
`see-all-the-history-from-the-wallet` passed on both platforms from fresh builds (iOS
simulator deleted, Android emulator shut down), and the final frames show the whole
history on each. Getting there exposed and fixed three runner defects: a wrong run name
that also stranded a simulator, a swipe that carried a page about 2.5 times further on iOS
than on Android (stories now swipe `until` a control is in reach), and a toast wait that
raced on slow runs. The controller itself has not yet run a task through this gate.
