priority: low

`MintCurrencyTabs` and the `SendScreen` methods container animate layout properties per frame; `MintAddScreen` picks its search header by `Platform.OS` because the glass bar has no slot for the URL validation state; `downloadedThemeRegistry` mutates imported theme constants in place; `PermissionGestureDemo` draws its own glove glyph because the icon registry stores every icon as 16x16.

**Not started on 2026-10-12: the first two parts are about motion and layout on a phone.** Replacing per-frame
layout animation with a transform or a layout transition has to be watched on both platforms (the per-row
`LinearTransition` bug in Reanimated is a known trap here), and giving the URL validation state a home in the
glass search bar is a layout decision on iOS and Android. The two code-only parts can be done first by an agent:
`downloadedThemeRegistry` should register and unregister themes through their owner instead of mutating imported
constants, and the icon registry should allow a size other than 16 by 16 so `PermissionGestureDemo` can drop its
own glyph.

## Done when

Transform or layout-transition based motion checked on devices; validation state has a home on both platforms; theme owners expose register/unregister
