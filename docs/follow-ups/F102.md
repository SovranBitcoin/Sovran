`app/modules/bitchat-module/scripts/patch-bitchat-imports.js` removes the guard that rejects an
announce whose peer id does not match the derived one, because App Store bitchat builds up to
v1.5.1 sent such announces. Whether v1.5.3 and later still do has not been checked.

## Done when

A current App Store bitchat build has been paired with the patch removed. If its announces are
accepted, the patch is deleted; if not, the version tested is recorded beside the patch.
