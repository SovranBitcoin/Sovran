Only `sovran:payment:1:` and `sovran:nearby:1:` are kept out of BitChat chat, matched literally in
`app/shared/providers/BitchatBLEProvider.tsx`, both native bridges and `useNearbyDiscovery.ts`. A version 2
payment reaching this build would be stored and drawn as a chat bubble holding locked proofs. Pinned in
`app/__tests__/bitchatSovranPrefixSuppression.test.tsx`. Nothing sends version 2 today.

## Done when

Before any version 2 ships, every build in use keeps the whole `sovran:` namespace out of chat, in JavaScript and in both native bridges.
