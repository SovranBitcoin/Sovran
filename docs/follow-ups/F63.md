priority: medium
needs: device

The library `Button` is gone. Its call sites (settings, design-system pages, sheet and toast
actions, keyring) now use `PillButton` (`app/shared/ui/primitives/PillButton.tsx`), which draws
the same rounded compact button, beside the shared `Button` (`app/shared/ui/primitives/Button.tsx`).
Neither carries `selected`/`checked`/`busy` accessibility state, so the design-system toggles
read as plain buttons. Decide whether `PillButton` folds into `Button` (a `compact` pill form)
or stays its own primitive, and add a selectable form, judged in the running app beside its
neighbours with a simulator and an emulator open.

## Done when

One compact-button primitive (or a stated reason for two), and selectable and busy buttons
expose that state to accessibility.
