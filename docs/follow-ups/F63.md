25 uses still import the library `Button` instead of the shared one (`app/shared/ui/primitives/Button.tsx`), because the shared button cannot carry `selected`/`checked`/`busy` accessibility state, be an icon-only ghost button, or sit inside the library's `Toast.Action`. Give the shared button those abilities (or a sibling `ToggleButton` for the selectable ones) and migrate them; four more files in the switched-off feed and composer modules were skipped.

**Not started on 2026-10-12: the shared button's new forms have to be seen.** Adding selected, busy, icon-only and
toast-action forms to `app/shared/ui/primitives/Button.tsx` (or a `ToggleButton` beside it) and moving 25 call
sites is ordinary work, but each site is a visible control, and the one-look rule here is that a variant is
judged in the running app beside its neighbours. Do it with a simulator and an emulator open, one form at a
time, each with its Design System page.

## Done when

No file outside the switched-off feed and composer modules imports the library `Button`; selectable, busy, icon-only and toast-action buttons use the shared button or a `ToggleButton` sibling.
