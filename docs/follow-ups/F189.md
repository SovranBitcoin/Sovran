title: "Applying a theme saves a wallpaper whose download failed"
priority: low
needs: decision
---

`themeDraft.commit` saves the chosen wallpaper even when its download failed and nothing retries it, so the colours
stay on the old theme. `app/__tests__/themeDraftCommit.test.ts` pins this. A catalog-supplied wallpaper name also goes
into a file path with no slug check (`wallpaperStorage.ts`); fixing that touches the shared schema package.

## Done when

Apply does not save a wallpaper that is not on the phone, or retries it; the name is checked before it becomes a path.
