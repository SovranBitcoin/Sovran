---
id: F187
title: "The swap toast can latch as mounted when no toast host is registered"
priority: low
needs: investigation
---

`swapStatusPopup` (`app/shared/lib/popup/popups/payment.ts`) sets its mounted flag before `showCustomToast`, which
returns without showing anything when no toast manager is registered; the flag then never clears and the swap toast
cannot appear again that session. Whether a swap can start before `PopupHost` mounts was not traced.

## Done when

The flag is set only when the toast was handed to the host, or the early start is shown to be impossible.
