title: "Recovery deletes pending mint operations for mints whose restore failed or was cancelled"
priority: high
needs: decision
---

`app/features/settings/screens/SettingsRecoveryScreen.tsx` (about lines 507 to 580): the end of a recovery run lists
and deletes every pending mint operation, on the stated ground that the proofs were recovered. That is false when a
mint's `addMint` or keyset restore failed, or the run was cancelled before the remaining keysets: the records a later
retry would use are gone. Traced, not run (`.surgery/pass-2/surveys/startup-accounts.md` D1 and candidate 1). Left because it changes which
saved Coco rows are deleted.

## Done when

A pending operation is deleted only for a mint whose restore succeeded, operations that appeared during the run are kept, and a test covers a failed mint and a cancelled run.
