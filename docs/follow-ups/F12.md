`app/scripts/vendor-marmot-ts.sh` resolves a missing source and records no revision or license.

**Script done on 2026-10-12; the revision of the copy already in the tree is what is left.**
`vendor-marmot-ts.sh` now looks for the checkout in the right place since the app moved into `app/` (it looked
one folder too low), refuses a checkout that is missing, has uncommitted changes or has no `LICENSE`, installs
from the lockfile, and writes the commit and origin to `app/vendor/marmot-ts/UPSTREAM`. The copy in the tree
(version 0.4.0, MIT) was vendored before any of this and no checkout of marmot-ts was available to this run, so
its commit is still unknown. With a checkout of `marmot-protocol/marmot-ts` at the commit that was vendored, run
`cd app && bun run vendor:marmot-ts` and commit the `UPSTREAM` file; if the build output differs from the tree,
that difference is the finding.
