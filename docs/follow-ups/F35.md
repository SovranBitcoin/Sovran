title: "clearUnitOverride releases the unit pin by value, so one binder clears another's pin"
status: open
priority: medium
needs: fix
---

`clearUnitOverride` in `wallet/src/react/ColadaProvider.tsx` releases the machine's unit pin by VALUE, not by owner: the NearPay radar and its peer list both pin `'sat'`, so the list unmounting clears the radar's pin until the radar's wallet context next changes. NearPay now refuses to start on a non-`sat` real unit, which hides the effect today.

## Done when

`setUnitOverride` returns a release function over a per-binder stack; a nested binder's unmount restores the previous pin; a machine test covers it
