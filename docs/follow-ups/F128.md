`ReceivePaymentRequestQuoteScreen.tsx` parses its route parameter with `amount: z.number().positive()`, so `1.5` passes into a flow that counts whole minor units. `app/shared/lib/routstr/api.ts` reads balance and msat fields as bare `z.number()`. Found by the review sweep (`conventions-zod/money-integer-schema`) and left; read again on 2026-10-12.

## Done when

Both schemas require a non-negative safe integer (the route entry a positive one), with a test that a fraction is turned down.
