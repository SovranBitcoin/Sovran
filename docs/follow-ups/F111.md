The JavaScript upgrade tests use an in-memory map for the keychain and Node's SQLite for databases. Only a real
install proves Keychain and Keystore behaviour, the native SQLite, and what survives an app update. Today only the
0.1.3 Android APK is archived; there is no simulator `.app` or `.ipa` for any release, EAS artifacts have expired,
and 0.1.0 and 0.1.1 had to be rebuilt from source. The upgrade steps are prose in the persistence skill.

## Done when

Each release archives a simulator `.app` and an APK; a script installs the previous release, creates a wallet,
installs the candidate over it and checks the balance and accounts on the iOS simulator and the Android emulator;
and one upgrade on a real iPhone through TestFlight is recorded per release.
