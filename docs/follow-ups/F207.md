Each pinned as it is. `useMintManagement`'s shared in-flight read is not tied to a Manager, so a new account mounting
mid-read can show the old account's mints (`mintManagementCache.test.ts`; whether the account reset always runs
first is unconfirmed). BitChat's incoming-DM account filter switches when a start is requested, not when native has
started (`bitchatBridgeLifecycle.test.tsx`). An AI answer cut off by an app kill stays pending for ever, and a failure
mid-stream loses the text already shown (`aiConversationBranchStream.test.tsx`). AppGate writes
`hasSeenOnboarding` during render on a reinstall (`appGateOrder.test.tsx`). `resume()` with nothing suspended never
settles (`accountSwitchBoundary.test.tsx`). Mint validation keeps showing the previous valid result while the next
value is checked (`debouncedMintValidation.test.ts`). The ambient NFC loop keeps scanning during a swap
(`useAmbientNfcArm.test.tsx`).
