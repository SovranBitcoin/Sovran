A route sheet that was open stayed on screen above the splash when the app was held or suspended. Closed on 2026-10-10: before the account tree is unmounted, navigation is sent back to its root when anything is presented, which closes the sheet (seen on the iOS simulator with the Receive sheet). Still open: that reset remounts the drawer, so for under half a second the outgoing account's first screen runs again before it is unmounted (on Android its focus hook can re-arm NFC); keeping the root route's key avoids the remount but did not close a sheet held by a nested navigator. Not checked on Android.

**Not started on 2026-10-12: it is a half-second flash that only shows on a phone.** The reset that closes an open
sheet remounts the drawer, so the outgoing account's first screen runs again briefly. Any fix (dismissing the
presented route without resetting the navigator, or unmounting under the splash first) has to be watched on an
iPhone and an Android phone with a sheet open while the account is held.

## Done when

Sheets are closed without remounting the outgoing account's screens, checked on both platforms.
