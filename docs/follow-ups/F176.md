id: F176
title: "A sheet's primary action closes the sheet before the action can show an error"
priority: medium
needs: decision
---

`ActionMenuHost` (`app/shared/blocks/popup/ActionMenuHost.tsx`) renders the primary action row without
`shouldCloseOnSelect={false}`, so the menu closes as soon as the row is pressed, before an async `onPress` calls
`setError`. Importing an invalid private key in `SettingsKeyringScreen` therefore shows nothing; the same holds for
every sheet that reports through `setError`. `app/__tests__/keyringImport.test.tsx` pins the keyring half (it calls
the callback through a mocked host). Left because the repair changes every sheet with a primary action: each caller
would have to close explicitly.

## Done when

An invalid key leaves the import sheet open with its error, proved through the real host, and no other sheet is left open by the change.
